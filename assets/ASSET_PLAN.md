# Leap of Faith Asset Production Plan

This file is the single source of truth for art/audio asset progress.

## 1) Folder Structure (Now in Repo)

- `assets/sprites/frogs/` - Player frogs and palette variants
- `assets/sprites/items/` - Firefly, fly, larva
- `assets/sprites/insects/` - Extra insect variants if needed
- `assets/sprites/board/` - Board tiles, highlights, markers
- `assets/sprites/ui/` - Card icons, buttons, HUD icons
- `assets/sprites/vfx/` - Jump arcs, collision impact, collect bursts
- `assets/sprites/portraits/` - Frog portraits / avatars
- `assets/backgrounds/` - Swamp backgrounds and overlays
- `assets/audio/sfx/` - Jump, eat, collision, UI sounds
- `assets/audio/music/` - Menu and match music
- `assets/audio/voice/` - Optional voice lines / announcer
- `assets/fonts/` - Bitmap or TTF fonts used in UI
- `assets/reference/` - Mood-boards, palette refs, sketches

## 2) Naming + Export Rules

- Use lowercase snake case file names.
- Keep transparent backgrounds for sprites.
- Keep consistent pivot/origin for animated frames.
- Keep animation frame order consistent across color variants.
- Prefer lossless `.png` for visual assets.
- Keep Aseprite source files as `.aseprite` next to exports or in a mirrored source folder.

Example names:
- `frog_green_idle_strip.png`
- `frog_green_jump_strip.png`
- `firefly_idle_strip.png`
- `board_tile_lily_01.png`
- `ui_ready_button.png`
- `sfx_jump_01.wav`
